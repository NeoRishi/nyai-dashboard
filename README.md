# NyAI Dashboard

Interactive web dashboard for **NyAI™ — A Nyāya-Grounded Artificial Human-Like Reasoning Agent**.

Built for **Unriddling Inference 2026**, IIT Delhi, April 12.

## Quick Start (Local)

```bash
# 1. Install backend
cd backend
pip install fastapi uvicorn

# 2. Build frontend (one-time)
cd ../frontend
npm install
npm run build    # outputs to backend/static/

# 3. Run
cd ../backend
uvicorn main:app --reload --port 8000
```

Open [http://localhost:8000](http://localhost:8000)

## Deploy to Railway

1. Push this repo to GitHub
2. Go to [railway.app](https://railway.app) → New Project → Deploy from GitHub
3. Railway auto-detects the Dockerfile and deploys
4. Add custom domain: `nyai.neorishi.io`
   - In Railway: Settings → Domains → Add Custom Domain
   - In Hostinger DNS: Add CNAME record `nyai` → `<your-railway-domain>`

## API Endpoints

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/health` | Health check |
| GET | `/api/scenarios` | List all 5 scenarios |
| GET | `/api/scenarios/{id}` | Run a scenario (s1-s5) |
| GET | `/api/scenarios/all/compare` | Run all + comparison table |
| POST | `/api/evaluate` | Evaluate a custom claim |
| POST | `/api/revise` | Test belief revision |
| GET | `/api/pramana-types` | List pramāṇa types |

## Architecture

```
frontend/          React (Vite) dashboard
  src/App.jsx      Single-file app with all views
backend/
  main.py          FastAPI server + static file serving
  nyai/            Core reasoning engine
    pramana.py     4 knowledge source types
    belief.py      Belief store with revision logic
    hetvabhasa.py  5 fallacy detectors
    pancavayava.py 5-step syllogism formatter
    reasoning_agent.py  NyAI + Naive agents
    scenarios.py   5 test scenarios
  static/          Built frontend (generated by Vite)
```
